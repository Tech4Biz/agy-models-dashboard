# AGY Models Dashboard

Project workspace for AGY Models Dashboard.

## Directory Structure

```
agy-models-dashboard/
├── src/              # Source code, tools, and implementations
├── assets/           # Brand assets, local reference documents
├── config/           # Project configuration files
├── drive/            # Symlink to project's Google Drive root
├── presentations/    # Symlink to Google Drive presentations
└── source-docs/      # Symlink to Google Drive source documents
```

## Google Drive Sync

To keep the local codebase lightweight while enabling collaborative document editing, the following folders are symlinked to Google Drive:
- `drive/`
- `presentations/`
- `source-docs/`
