# AGY Models Dashboard Developer Guide

## Core Commands
- Build: `npm run build` or standard build command (adapt as needed)
- Test: `npm test` or standard test command (adapt as needed)
- Lint/Format: `npm run lint` or `npm run format` (adapt as needed)

## Workspace Rules
- Place reusable source code and script tools under `src/`
- Put local asset assets under `assets/`
- Configure metadata and JSON config files in `config/`
